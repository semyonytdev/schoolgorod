# schoolgorod — Школа-город

Мод для Minecraft Fabric 1.21.11 (Java 21, нужен Fabric API). Проект в разработке.

## Реализовано

- Розовый осколок и розовый скалк с двойным опытом.
- Три кузнечных шаблона и вишнёвая доска из осколка.
- Таблицы лута для школы, раздевалок, туалета и заброшенного класса.
- Класс�� Java для сущностей «Ученик», «Учитель» и «Директор» с атрибутами и базовыми ИИ-целями.

## Следующий этап

Зарегистрировать яйца призыва и клиентские рендереры, добавить розового крикуна с его звуковой атакой, структуру школы на три этажа и автоматическую генерацию.

Сборка: `gradle build`.
