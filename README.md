# schoolgorod — Школа-город

Мод для Minecraft Fabric 1.21.11 (Java 21, нужен Fabric API). Проект в разработке.

## Уже реализовано

- Розовый осколок с редкостью EPIC и крафт из него двух вишнёвых досок.
- Розовый скалк, который выдаёт 2 опыта, и таблица дропа при добыче с «Шёлковым касанием».
- Три кузнечных шаблона-узора: Учитель, Вишня и Главный босс.
- Таблицы лута для классов, обычных и редких раздевалок, тайника директора, туалетного тайника и заброшенного класса. В них настроены указанные шансы золотых и зачарованных золотых яблок.

## Ещё не реализовано

Генерация подземного города-школы и его комнат/сундуков, команды поиска структуры, кастомные существа (ученики, розовый крикун и директор), босс-бар, музыка и специальные награды за босса. Таблицы лута уже подготовлены, но пока не подключены к сундукам структуры.

Сборка: `gradle build`.
