# schoolgorod — Школа-город

Мод для Minecraft Fabric 1.21.11 (Java 21, нужен Fabric API). Проект в разработке.

## Реализовано

- Розовый осколок, розовый скалк с двойным опытом и три кузнечных шаблона.
- Таблицы лута для школы, раздевалок, туалета и заброшенного класса.
- Сущности ученика, учителя и директора с базовыми характеристиками; для них добавлены яйца призыва и клиентские рендереры на моделях зомби/вардена.
- Музыкальный алиас на ванильную пластинку Otherside: `/function schoolgorod:music_start` включает, `/function schoolgorod:music_stop` выключает.

## Ещё не готово

Собственная музыкальная композиция/звуковой файл, уникальные модели и текстуры существ, розовый крикун, автоматическая генерация подземного города и поиск через `/locate`, специальные комнаты, интегрированный босс-ивент.

Сборка: `gradle build`.
