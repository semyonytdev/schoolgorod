# schoolgorod — Школа-город

Мод для Minecraft Fabric 1.21.11 (нужен Fabric API). Подземная школа в городе Вардена.

**Этап 1** (сейчас): розовый осколок (из него крафтятся вишнёвые доски), розовый скалк (2 опыта), три розовых кузнечных шаблона (Учитель, Вишня, Главный босс) с узорами брони.

Дальше: учитель/ученики/директор, школа-структура, лут, музыка.
